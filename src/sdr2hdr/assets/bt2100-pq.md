# BT.2100 PQ ICC profile

`bt2100-pq.icc` is a CC0 profile generated by libjxl 0.12.0 (its embedded
copyright tag is `CC0`). It describes full-range RGB, BT.2020 primaries and
ST 2084 PQ, including ICC v4.4 CICP values 9/16/0/1. No photograph is embedded.

Reproduction from this project's environment and the official JPEG XL decoder:

```sh
python -c "import numpy as np; from sdr2hdr.io import save_image_hdr; save_image_hdr('profile.jxl', np.zeros((16,16,3), dtype=np.uint16))"
djxl profile.jxl profile.ppm --icc_out=bt2100-pq.icc --quiet
```

Source: https://github.com/libjxl/libjxl/tree/v0.12.0

On macOS the exporter obtains the system's ITUR_2100_PQ profile through
CoreGraphics instead. ColorSync recognizes that profile as HDR; it did not
recognize this libjxl ICC as an ITU-R 2100 transfer function in the tested
macOS 26.6.2 environment. The bundled profile is used on other platforms;
Windows HDR display has not been verified.
